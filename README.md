# Hi, I'm Ryan

I build practical software around computer vision, applied machine learning, automation, and data-heavy workflows. I enjoy taking an ambiguous real-world problem, turning it into a reproducible pipeline, and giving people a usable interface for the result.

## Current interests

- Computer vision and desktop automation
- Geospatial analysis and remote sensing
- Applied AI products with local and hosted models
- Search, simulation, and constraint-solving systems
- Python backends and TypeScript/React interfaces

## Featured projects

### [Ziply Solver](https://github.com/barnardrc/ziply-solver)

An experimental pipeline that uses screen capture, OpenCV, OCR, and constraint solving to reconstruct and solve a visual path puzzle.

### [Speed Reader](https://github.com/barnardrc/speed-reader)

A desktop rapid-serial-visual-presentation reader for EPUB and PDF documents, with optional local AI assistance and eye-tracking experiments.

### [Voice Transcription](https://github.com/barnardrc/voice-transcription)

An exploratory local speech pipeline combining transcription, voice activity detection, and speaker-embedding tools.

### [Shut the Box](https://github.com/barnardrc/shut-the-box)

A reproducible Monte Carlo simulation for comparing strategies in the dice game Shut the Box.
